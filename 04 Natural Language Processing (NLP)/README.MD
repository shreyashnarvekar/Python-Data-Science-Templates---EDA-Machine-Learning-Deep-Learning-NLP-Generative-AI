# CHATBOT 

## Create an account on Langchain
Step 1 : Go to setting and Generate API key

Step 2 : Create '.env' file in project directory and paste it into langchain api key

    ```
        LANGCHAIN_API_KEY='API_KEY_HERE'
        OPENAI_API_KEY='API_KEY_HERE'
        LANGCHAIN_PROJECT='PROJECT_NAME_HERE'
    ```

## OLLAMA
Step 1 : Download & Install Ollama 
Step 2 : Open terminal and download llm model
    Terminal Prompt => ollama run llama2  


## RUN APPLICATION
Open Terminal => streamlit run localama.py
